## 三种使用方法

### 已知类名

先进入源码索引确认模块、职责和上游/下游对象，再返回对应阶段主笔记理解完整链路。

### 已知故障现象

先走故障决策树确定失败边界，然后按断点表采集 URL、Invocation、Invoker 列表、requestId、异常码和资源 identity。

### 准备升级或复习

先做复习题并口述总链路；升级时复制差异清单，为新版本单独记录源码变化、对象树差异和实验结果。
